03 — 사보 자동 채점

오선지에 써낸 악보,
촬영 즉시 실시간 채점

더 이상 채점을 위해 오프라인 선생님을 기다릴 필요가 없습니다. 손으로 직접 쓴 사보 답안지를 카메라로 찍어 업로드하면 AI가 실시간으로 분석합니다.

  • CV 기반 악보 인식: 경량화 Vision 모델로 사보 사진 정밀 인식
  • MIDI 데이터 변환 채점: 정답 MIDI 데이터와 비교해 음악 구조 단위로 분석
  • 실시간 채점과 피드백: 실시간으로 사보 채점 결과와 오답 체크 가능
